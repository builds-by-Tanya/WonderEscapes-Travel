# Wonder Escapes

Wonder Escapes is a responsive luxury travel discovery website inspired by editorial travel publications. It helps visitors explore curated destinations, browse travel experiences and packages, and discover memorable journeys around the world.

## Overview

The website uses a warm, nature-inspired visual style with an elegant serif and sans-serif typography pairing. Its interface includes:

- Destination search and category filtering
- Interactive destination and package details
- Travel experience categories
- A client-side newsletter form
- Responsive navigation and mobile menu
- Accessible keyboard interactions
- Toast notifications

## Built With

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)

No frameworks or build tools are required.

## Website Sections

1. **Navigation** - Desktop and mobile navigation with quick destination search.
2. **Hero** - Editorial headline, primary calls to action, and travel highlights.
3. **Destination Explorer** - Searchable and filterable destination cards.
4. **Travel Experiences** - Mountain, coastline, heritage, and luxury travel pathways.
5. **Featured Trips** - Curated packages with durations, group details, prices, and itineraries.
6. **Why Wonder Escapes** - Curated experiences, personal planning, local guides, and memorable journeys.
7. **Testimonials** - Traveler reviews presented in an editorial style.
8. **Newsletter** - Gazette sign-up form with client-side email validation.
9. **Footer** - Brand information, navigation, contact details, social links, and legal links.

## Run Locally

Open `index.html` directly in a browser, or serve the project with a local HTTP server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

You can also use a Live Server extension in your code editor.
